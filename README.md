# @webship-js/redmine-steps

Cucumber step definitions for Redmine, the open-source project management and issue tracking software, a pack for
[webship-js](https://github.com/webship/webship-js) (Playwright and Cucumber): logging in, a project, the issue list
and one issue, its status, notes and time spent, a new issue, and the roadmap of its versions.

The steps, their documentation and CI come with the first release, `2.0.0`.
